# cos4yan.github.io

Public home page, privacy policy and terms for **Cosmo**, Aryan's private, single-user AI agent (built on [Hermes Agent](https://github.com/NousResearch/hermes-agent)).

These pages exist because Google requires a home page and privacy policy link before an OAuth app can be published. Cosmo uses that app to access its own Google account (cos4aryan@gmail.com).

- Home: https://cos4yan.github.io/
- Privacy: https://cos4yan.github.io/privacy.html
- Terms: https://cos4yan.github.io/terms.html

Not a public service. Contact: cos4aryan@gmail.com
